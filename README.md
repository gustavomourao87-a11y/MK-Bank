# 🏦 MK Bank

Uma aplicação bancária **front-end demonstrativa**, desenvolvida com **HTML, CSS e JavaScript puro**, com foco na criação de uma interface moderna, responsiva e interativa.

O projeto foi desenvolvido durante meus estudos de desenvolvimento web para colocar em prática conceitos de **JavaScript, manipulação do DOM, gerenciamento de estado, criação de componentes reutilizáveis, formulários e responsividade**.

> ⚠️ **Aviso:** este projeto é exclusivamente demonstrativo. Os dados, transações e operações financeiras são simulados e não representam um sistema bancário real.

## 📸 Sobre o projeto

O MK Bank simula a experiência de um banco digital, permitindo navegar por diferentes áreas da aplicação através de uma interface semelhante a um sistema bancário real.

A aplicação possui uma tela de login demonstrativa e, após o acesso, apresenta um painel com informações financeiras simuladas e diferentes funcionalidades.
